# Contributing / 参与贡献

Fork, create a feature branch and open a pull request. Do not push directly to the maintained public branch, private main or release tags. Only the repository owner may authorize merging/releasing. Opening a PR does not authorize an agent/collaborator to merge it. No automatic merge/release workflow is included.

Describe behavior, privacy impact and relevant checks. Do not include classroom recordings, transcripts, identifiable screenshots, secrets, local paths or signing keys. Test fixtures must be synthetic or redistributable with permission. Preserve licenses and source attribution. UI changes must fit both English and Chinese. Do not incidentally change audio retention/networking.

Intentional contributions are offered under Apache-2.0 unless an alternative agreement is explicitly stated. Identify third-party sources and licenses.

中文：Fork后用功能分支发PR，必须由所有者明确批准后才合并/发布，不提供自动合并。禁止提交私人课堂资料、密钥或机器路径。说明隐私影响及相关检查，保留第三方许可，同时适配中英文。
