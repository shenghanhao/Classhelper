# Security and privacy / 安全与隐私

Never include secrets or real classroom material in public issues. If the repository enables GitHub private vulnerability reports, use **Security → Report a vulnerability**. Otherwise request an owner-approved private channel; no personal address is bundled.

Experimental software does not guarantee accuracy, uninterrupted capture or compatibility. Process only media you may lawfully use. Shared documents may contain personal/copyrighted information. No signing keys are included; Debug APKs are test artifacts, not a production update channel.

中文：敏感内容不要发到公开Issue。使用仓库启用的私密漏洞报告，或先询问维护者私下报告方式。分享导出前检查隐私与版权。测试版不是可靠的生产更新渠道。
